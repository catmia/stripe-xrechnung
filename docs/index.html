stripe-xrechnung

Offline Python library and CLI that maps Stripe Invoice JSON (including invoice.finalized event wrappers) to XRechnung 3.0.2 UBL 2.1. No Stripe API calls, no Peppol access point, never invents a VAT ID. Local structural and VAT-math checks; not a substitute for the official KoSIT validator.
